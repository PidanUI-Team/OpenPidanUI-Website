OpenPidanUI 的组件跑在 **Rainmeter** 上，所以第一步永远是先把 Rainmeter 装好。

按顺序读完前两篇，就能在桌面上看到效果：

1. [安装 Rainmeter](/docs/user/install-rainmeter)
2. [导入小组件](/docs/user/import-widget)
3. [组件设置](/docs/user/settings)
4. [常见问题](/docs/user/faq)

> 组件不修改任何系统文件。所有改动都在 Rainmeter 的皮肤目录里，想还原只要切回默认主题（或者直接卸载皮肤）。
