本文将引导你一步一步地安装 Rainmeter。OpenPidanUI 的 Rainmeter 小组件对 Rainmeter 版本的最低要求是 `5.0 RC1`。

## 安装步骤

安装 Rainmeter 的方式有两种，一种是通过输入 `winget` 命令安装，另外一种是访问官网下载安装包。

<details><summary>winget 命令安装</summary>

### `winget` 命令安装

> 由于 Rainmeter 5.0 正式版尚未发布（`winget` 源的版本还是 `4.5.28.3936`），所以此方法暂时折叠。

以管理员身份打开 PowerShell，并执行以下命令：

```powershell
winget install --id Rainmeter.Rainmeter
```

> 如果出现 `[Y/N]` 提示，全部输 `Y` 并回车即可。

在命令执行完毕后，如果你可以在开始菜单看到 Rainmeter 的快捷方式，那么说明 Rainmeter 已经安装成功。

</details>
